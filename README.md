# Lico — LiteGapps Controller

Lico is an Android app for managing LiteGapps and LiteGapps++: Gapps check and fixes, performance
tweaks, gaming mode, device props and more. It has a Material 3 design with dynamic color, and runs
in **root** (Magisk, KernelSU or APatch) or **non-root** mode.

This repository hosts **releases only**.

## Download

Get the latest APK from [Releases](https://github.com/litegapps/litegapps-controller/releases).
It requires Android 8.0 or newer.

## Legacy module

The old LiteGapps Controller flashable module (terminal menu) is discontinued. Its last release
is [v1.3](https://github.com/litegapps/litegapps-controller/releases/tag/stable). `update.json` and
`changelog.md` stay here so installed copies can still check for updates.
